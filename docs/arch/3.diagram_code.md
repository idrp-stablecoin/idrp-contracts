## Technical Flow

### 1. Mint Operation Technical Flow

##### Diagram Code
```
sequenceDiagram
    participant RH as Role Holder
    participant IC as IDRPController.sol
    participant IDRP as IDRP.sol
    
    RH->>IC: executeOperation(OperationType.Mint, address(0), amount, operationIdentifier, deadline, signatures)
    Note over IC: 1. Get quorum rule
    Note over IC: 2. Calculate operationHash
    Note over IC: 3. Verify signatures
    IC->>IDRP: mint(amount)
    Note over IDRP: 4. Check if depository wallet is frozen
    Note over IDRP: 5. Create tokens: _mint(depositoryWallet, amount)
    IDRP-->>IC: Return success
    Note over IC: 6. Mark operation as used
    Note over IC: 7. Emit OperationExecuted event
    IC-->>RH: Return success
```

### 2.1 General Signature Verification
```mermaid
flowchart TD
    A[verifySignatures] --> B{Operation hash already used?}
    B -->|Yes| C[Revert: Operation already executed]
    B -->|No| D[For each required role]
    D --> E[roleFound = false]
    E --> F[For each signature]
    F --> G[Recover signer from signature]
    G --> H{Signer has required role?}
    H -->|Yes| I[roleFound = true]
    H -->|No| J{More signatures?}
    I --> L
    J -->|Yes| F
    J -->|No| L{roleFound?}
    L -->|No| M[Revert: Missing required role signer]
    L -->|Yes| N{More required roles?}
    N -->|Yes| D
    N -->|No| O[Return success]
```

### 2.2 Special Unpause Signature Verification
```mermaid
    flowchart TD
    A[verifyUnpauseSignatures] --> B{Operation hash already used?}
    B -->|Yes| C[Revert: Operation already executed]
    B -->|No| D[Process all signatures]
    D --> E[Identify signer roles]
    E --> F{Check for valid combinations}
    F --> G{Officer + Manager + Director?}
    G -->|Yes| J[Continue with unpause]
    G -->|No| H{Manager + Director + Commissioner?}
    H -->|Yes| J
    H -->|No| I[Revert: Invalid signature combination]
```
